# 🧹 CleanTrack Time Planner

**Built with Python by Heider Jeffer**

### ⏱️ Smart Cleaning Time Management

[🌐 Launch CleanTrack Time Planner](https://3c7hth9srl6meaocdpn8tw.streamlit.app/)

**CleanTrack Time Planner** is a simple and practical Streamlit application designed to help cleaning workers **organize their working time, manage their daily cleaning schedule, and stay on track throughout the day**.

> **Know what to clean, how much time you have, and how much time you can spend on each room.**

---

## ✨ Features

* 🛏️ **16 Rooms** — Track a full day of cleaning across 16 rooms.
* ⏰ **Time Management** — Automatically calculates the available working time.
* ☕ **20-Minute Break** — Accounts for the scheduled 10:00 AM–10:20 AM break.
* 📊 **Cleaning Progress** — See completed and remaining rooms.
* ⏳ **Minutes per Room** — Calculates the available time for each remaining room.
* 🎯 **Expected Finish Time** — Estimates when the day's work should be completed.
* 🗓️ **Room-by-Room Plan** — Creates a practical schedule for the remaining rooms.
* 🚿 **Corridor Tracking** — Track corridor completion.
* 📝 **Worker Notes** — Add notes for individual rooms.

## 🎯 Project Goal

CleanTrack Time Planner was created to make everyday cleaning work **easier to organize and manage**.

Instead of manually calculating how much time is left, the worker enters:

**Current Time → Rooms Completed → Corridor Status**

The application calculates:

**Time Remaining → Minutes per Room → Expected Finish → Room Schedule**

This allows the worker to focus on cleaning rather than doing time calculations during the working day.
